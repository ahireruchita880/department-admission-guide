# Department Admission Guide

## Project Overview
Department Admission Guide is an AI-powered chatbot developed using n8n and Google Gemini to help students find information about Computer Engineering admissions at SNJB.

## Objectives
- Answer common admission-related questions.
- Guide students about eligibility and required documents.
- Provide official college admission links.
- Make admission information easier to access.

## Technologies Used
- n8n – Workflow automation
- Google Gemini API – AI language model
- Chat Trigger – User interaction
- AI Agent – Processes questions and generates responses

## Workflow
Chat Trigger → AI Agent → Google Gemini Chat Model

## Official Links
- College website: https://snjb.org/
- First-Year B.Tech admissions: https://snjb.org/engineering/admissions/fy-btech
- Direct Second-Year admissions: https://snjb.org/engineering/admissions/direct-second-year-engineering

## Note
Students should verify important admission details, fees, and deadlines through official college sources.
